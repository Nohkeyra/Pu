# Orchestration Skill

Coordinate multiple skills without duplicating work.

- Treat the router as a planning layer, not a substitute for domain skills.
- Prefer one shared evidence set over repeated independent inspection.
- Parallelize independent read-only investigations when tools support it.
- Sequence dependent work: discovery/understanding before implementation; implementation before final verification.
- Merge findings by root cause, not by agent or skill.
- Resolve contradictions using stronger evidence and mark uncertainty.
- Do not let one skill silently override another; reconcile constraints explicitly.
- Keep the active skill set proportional to task complexity.
- After any material scope change, re-evaluate routing.
