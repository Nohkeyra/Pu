# SKILL: SECURITY REVIEW

Review actual trust boundaries and attack paths, not generic checklists alone.

Inspect:
- authentication and authorization boundaries
- server-side enforcement
- untrusted input handling
- secrets and credentials
- data exposure
- privileged operations
- injection risks
- unsafe deserialization or file handling
- client/server trust assumptions

For each finding provide severity, location, concrete attack/effect path, evidence, and remediation direction.
Prefer high-confidence, actionable findings over theoretical noise.
