# SKILL: CODE AUDIT

Purpose: rigorous assessment of an existing codebase.

1. Discover project structure and entry points.
2. Read package/build/configuration files.
3. Locate business logic, UI, services, APIs, data models, auth, and tests.
4. Trace critical flows end-to-end.
5. Review correctness, regressions, state/data flow, error handling, security, performance, maintainability, and test coverage.
6. Group symptoms by root cause.
7. Rank findings by impact and confidence.
8. Every concrete finding must include file/location and evidence.
9. Do not report speculative problems as facts.
10. Do not expand scope merely to produce more findings.
