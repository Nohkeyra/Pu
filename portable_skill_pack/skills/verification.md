# SKILL: VERIFICATION

Independently validate the requested result.

Choose the strongest practical checks available. Prefer actual execution over static confidence.

Check as applicable:
- syntax/type errors
- lint
- unit/integration tests
- production build
- runtime behavior
- browser/device behavior
- API/database behavior
- regression behavior

Report exact commands/checks performed when available and distinguish PASS, FAIL, BLOCKED, and NOT_RUN.
