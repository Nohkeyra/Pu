**1. Skop dan kefahaman aplikasi**

Inventori asas merangkumi 731 fail dijejak: 238 di `src`, 55 di `server`, 123 di `android`, 220 di `public`, 20 skrip, 9 fail E2E, konfigurasi, token tema, dokumentasi dan aset. Inventori, rujukan/import, konfigurasi dan skrip diperiksa; ini bukan dakwaan setiap aset telah diperiksa secara visual atau setiap laluan dijalankan dengan perkhidmatan sebenar.

Aplikasi mengurus permohonan katering, profil pelanggan, semakan pentadbir, kalendar, invois PDF dan notifikasi. React 18/TypeScript/Vite membekalkan web dan aset Capacitor 8 Android. Express menyediakan API; Firebase Auth membuktikan identiti; Firestore menyimpan data dan menguatkuasakan akses bacaan terus pelanggan. Backend Admin SDK memintas rules, maka pemeriksaan akses API perlu berasingan. Integrasi lain termasuk SMTP, Google Calendar, eksport Excel, MCP OAuth, peta, GPS dan widget Android.

Aliran penting yang dijejak: borang → pengesahan identiti/e-mel → validasi API → transaksi/idempotensi → Firestore → kalendar/notifikasi; pengesahan pentadbir → mutasi status/harga → barisan invois → PDF/e-mel; bacaan profil dan kalendar; tempahan tersimpan; sesi penjejakan; kemas kini aplikasi dan pakej Android. Arahan `AGENTS.md`, dokumentasi struktur/visual, rules, kod pengesahan, perkhidmatan invois serta skrip build Android dibaca sebelum perubahan berkaitan.

**3. Pembersihan dan pakej**

Empat fail di bawah telah disahkan tiada rujukan runtime melalui import statik/dinamik, CSS, konfigurasi, skrip, Android dan ujian; dokumentasi projek serta `DELETE_FILES.txt` sedia ada juga menandakannya sebagai diganti. Modul SVG aktif ialah `KraftLunchboxArtwork.tsx`.

```text
public/assets/living-canvas/kraft-lunchbox.svg
src/pages/living-canvas-v31.css
src/styles/wawasan-creative-v6.css
src/styles/wawasan-editorial-v2.css
```

ZIP mengandungi fail ditambah/diubah sahaja, pada laluan asal dari akar repositori. Ia tidak mengandungi empat fail terpadam, `.env`, rahsia, `.git`, `node_modules`, output build, cache, screenshot atau konfigurasi ujian sementara persekitaran. Salin kandungannya ke checkout asas yang sepadan, kemudian padam tepat empat laluan dalam senarai pemadaman. Jangan biarkan implementasi CSS lama bersebelahan fail gantian. Manifest berasingan menyenaraikan SHA-256 bagi kandungan pakej.

Perubahan backend dan `firestore.rules` perlu digunakan bersama dalam keluaran yang diluluskan kelak. Tiada tindakan penerbitan dilakukan oleh audit ini. Rekod pembatalan sesi Firebase sengaja tidak mempunyai TTL; memadamkannya boleh menghidupkan semula sesi lama yang masih mempunyai credential pembaharuan.
